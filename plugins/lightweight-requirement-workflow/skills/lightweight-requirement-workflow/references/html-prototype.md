# HTML 高保真原型

## 视觉确认门槛

生成前必须确认：使用场景、目标设备、风格关键词、主色/辅助色、现有产品或参考图。将结论保存到 `visual_direction.md`；缺失时先提问，不自行套模板。

## 输入优先级

1. 已确认视觉方向和真实产品资产
2. `prototype.md`
3. `prd.md` 与 `user_story.md`
4. SVG 线框

文档冲突时停止并报告，不以 SVG 覆盖需求基线。

## 输出要求

- 固定入口：`prototype_html/index.html`。
- 原生 HTML、CSS、JavaScript；单文件优先，多文件只在明显提升维护性时使用。
- 必须离线可运行：不使用 CDN、远程字体、远程图片或远程图标。
- 使用系统字体、本地资产、内联 SVG 或简单 CSS 图形。
- 实现核心页面切换、表单校验、弹窗、Toast、返回和关键状态切换。
- 使用模拟数据，不放真实手机号、地址、账号、位置或健康隐私。
- 不实现真实后端、支付、消息发送或外部写入。

## 视觉与响应式

- 遵循用户确认的品牌方向，不把所有区域都做成卡片。
- 移动端保证触控目标、底部安全区和无横向溢出。
- 桌面端限制内容宽度并保持工作区信息层级。
- 文字不得截断、遮挡或撑破按钮。

## 验证

使用环境中可用的浏览器能力验证主流程、错误/空/成功状态、桌面和移动视口、控制台错误及资源加载。若浏览器安全策略阻止本地页面测试，如实记录，不伪造通过。保存 `prototype_html/design_qa.md`，结论只能为 passed、passed_with_warnings 或 failed。
